# 語灯 (ごとう)

浄土宗の辞書と勤行(おつとめ)を、スマートフォンで引くためのWebアプリ(PWA)です。
辞書を引く道具としてだけでなく、**引いた言葉から典拠へ渡れる**ことを目指しています。

> [!IMPORTANT]
> **これは個人が開発中のプロトタイプであり、浄土宗の公式アプリではありません。**
> 表示内容の正確性を保証するものではないため、正式な内容は必ず出典にあたってください。

公開先: <https://letticia.github.io/gotou/>

## できること

- **辞書を引く** — 読み(ひらがな)の前方一致検索。旧字体・異体字は自動で吸収します。
  オフラインで動きます。検索前の画面には収録語をいくつか紹介し、思いがけない語に
  出あえるようにしています。
- **典拠へ渡る** — 本文中の『浄土宗全書』『大正蔵』の出典表記から、
  該当ページへ1タップで移動できます。
- **一節から典拠をさがす** — 法語や偈文の一節を貼り付けると、出典の候補を
  ①辞書の項目 ②勤行テキスト ③浄土宗全書 の3層で探します。
- **勤行モード** — 差定(さじょう＝式次第)をプレイリストのように扱い、
  縦書きの経本表示で読誦できます。片手で画面をタップしてページを送れます。
  読誦中はいつでも式次第を見渡せ、中断してしまっても「続きから」で戻れます。
- **日替わり御法語** — 『元祖大師御法語』(前篇31章・後篇31章)から、その日の
  日付と同じ番号の章を毎日のおつとめに組み込めます。

## 使い方

### はじめに — ホーム画面に追加する

辞書データを使うには、まず**ホーム画面への追加(インストール)が必要**です。
ブラウザの共有メニュー等から「ホーム画面に追加」を選んでください。

追加したアプリを開くと「ダウンロード開始」が出ます。押すと辞書データの取得が
始まります(約9,200項目。回線によっては数分かかります)。
**一度取得すれば、以後はオフラインで使えます。**

### 辞書を引く

- 何も入力していないときは「**収録語から**」に何語かを紹介します。タップするとその項目が
  開きます。「ほかの語を見る」で引き直せます。
- 入力欄に**読み(ひらがな)**または**見出し語**を入れると、前方一致で候補が絞られます。
- 旧字体・異体字は自動で吸収します(「彌」で「弥」、「佛」で「仏」など)。
- 「A-」「A+」で文字の大きさを変えられます。
- 本文中の**橙色のリンク**は他の項目へのリンクです。タップするとその項目へ移動し、
  「戻る」で元の項目に帰れます。
- 末尾に「↗」が付いたリンクは**典拠リンク**です。浄土宗全書テキストデータベースや
  SAT大正蔵の該当ページを、新しいタブで開きます(初回だけ確認が出ます)。

### 一節から典拠をさがす

「この一節、出典はどこだったか」を調べる機能です。

1. 入力欄の下のトグルで「**一節から典拠をさがす**」に切り替えます。
2. 入力欄が広くなるので、調べたい一節を貼り付けます(手入力・音声入力も使えます)。
3. 結果が3つのグループで出ます。
   - **辞書の項目** … その一節を引用・解説している項目。タップで本文へ。
   - **勤行テキスト** … 収録されている偈文と、それを含む差定の名前。
   - **浄土宗全書テキストデータベース** … 手元に無い場合の全文検索。
     結果は外部サイトから直接読み込んで表示します。

辞書の本文を読んでいるときに**一節を範囲選択**すると、画面下に
「この一節の典拠をさがす」が出ます。そのまま逆引きに渡せます。

### 勤行モード

下のタブで「勤行」に切り替えます。

1. 「**差定を選ぶ**」から、読むおつとめを選びます。
2. 差定名が出る**扉の画面**をタップすると始まります。
3. **画面をタップするとページが進みます。** 片手で持って親指で送れます。
4. 戻るときは左上の「← 前へ」。
5. 最後まで読むと「おつとめ、終わりです」が出ます。タップすると差定選択に戻ります。

#### いまどこを読んでいるか

- ヘッダー右の「**≡ 2 / 18**」が、式次第の何番目かを示します。画面のいちばん上の
  細い帯は全体の進み具合です。
- この「**≡ 2 / 18**」を押すと**式次第の一覧**が開きます。読み終えた偈文は薄く、
  いま読んでいる偈文には「いまここ」が付きます。
- 一覧の**偈文を選ぶとその先頭へ飛べます**。十念のように何度も出てくる偈文も、
  左の番号で見分けられます。

#### 中断してしまったとき

おつとめの途中でアプリが閉じてしまっても、位置は覚えています。
もう一度開くと、差定名の出る扉の画面に「**続きから ─ ◯◯**」が出ます。

- 押すと中断したところから続けられます(数えかけの十念の残り回数も戻ります)。
- 押さずに画面をタップすれば、いつもどおり**はじめから**です。
- 半日たった中断位置や、読み終えたおつとめについては出ません。

そのほか:

- ヘッダーの「**横書き / 縦書き**」で表示を切り替えられます(既定は縦書きの経本表示)。
- 十念・三唱礼は、既定では名前を1回示すだけで次に進みます。
  回数を数えながら唱えたい場合は設定で切り替えてください。

#### 日替わり御法語

差定を選ぶ画面の「**日常勤行式（四奉請・日替わり御法語版）**」または
「**（三奉請・日替わり御法語版）**」を選ぶと、一枚起請文のところが
その日の御法語に替わります。

- **その日の日付と同じ番号の章**を読みます(1日なら第一章、30日なら第三十章)。
  知恩院の「今日のお言葉」と同じ数え方です。
- 章は31までなので、**第29〜31章はその日がある月にだけ**登場します
  (2月は第29章まで、小の月は第30章まで)。
- 扉の画面に「本日の御法語: 前篇第三章 聖浄二門」と出ます。
- **前篇・後篇のどちらを読むか**は設定で選べます(既定は前篇)。
- 章はおつとめを始めるときに決まり、読んでいる途中で入れ替わることはありません。
  日付をまたいで「続きから」で再開したときは、その日の章になります。

#### 差定を自分用に整える

- 用意されている差定は**雛形**です。「**複製して編集**」すると自分の差定になります。
- 自分の差定(「マイ差定」)は、偈文の並べ替え・オンオフ・回数の指定ができます。
- 「**共有**」からQRコードやURLで受け渡しできます。受け取った側は開くだけで
  取り込みの確認が出ます。JSONを貼り付けて読み込むこともできます。

### 設定

右上の歯車から開きます。

- **フォント** — 辞書と勤行の本文の書体(Noto Serif JP / Zen Old Mincho / Klee One)
- **十念・三唱礼の数え方** — 簡易表示(既定)/ 回数を数えながら唱える
- **日替わり御法語の篇** — 前篇(既定)/ 後篇
- **使い方** — この節と同じ内容をアプリ内で読めます
- **このアプリについて** — 出典やライセンスの情報

### オフラインでの利用

辞書と勤行はオフラインで使えます。ただし典拠リンクと浄土宗全書の検索は
外部サイトを開くため、通信できる状態が必要です。

## データについて

- **辞書データはこのリポジトリに含まれていません。** 利用者の端末が起動時に
  取得し、その端末の中だけに保存されます。
- 辞書の項目・本文は[浄土宗大辞典](https://jodoshuzensho.jp/daijiten/)を出典としています。
  本アプリは浄土宗大辞典と提携・協力関係にはありません。
- 勤行モードの経文・回向文等は、著作権保護期間の満了した原文(パブリックドメイン)に
  基づき、開発者が入力・校正したものです(`shared/gongyo/`)。
- 御法語の本文は法然上人遺文からの抜粋(パブリックドメイン)です。本文・読み仮名・
  章題は知恩院公式サイト「御法語」より取得しました(`shared/gohogo/`。詳細は
  同ディレクトリのREADME)。同サイトの現代語訳は収録していません。
- 典拠リンク先の[浄土宗全書テキストデータベース](https://jodoshuzensho.jp/jozensearch_post/)・
  SAT大正蔵の内容は、利用者のブラウザが直接読み込みます。本アプリはその本文を
  取得も保存もしません。

## 技術構成

| | |
| --- | --- |
| アプリ | TypeScript / React / Vite の PWA(Service Workerは自前実装) |
| 辞書DB | SQLite(`@sqlite.org/sqlite-wasm`)。ブラウザ内で構築しCache APIに保存 |
| データ工場 | Python。MediaWiki → SQLite / macOS .Dictionary 変換 |
| 配信 | GitHub Pages(GitHub Actionsで自動デプロイ) |

```
app/       … PWA本体(TypeScript / React)
factory/   … Pythonのデータ工場
shared/    … app と factory の契約(スキーマ・異体字テーブル・勤行テキスト)
docs/      … 設計文書と決定の経緯
```

`app/` と `factory/` は互いに直接依存せず、`shared/` の契約だけを介してつながります。

## 開発

### アプリ

```bash
cd app
npm install
npm run dev
```

```bash
npm test          # vitest
npm run build     # 型検査 + ビルド
```

開発サーバーでは、テスト用のダミー辞書(`factory/tests/fixtures/` の自作100件)を使います。

### データ工場

```bash
cd factory
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

詳細は [factory/README.md](factory/README.md) を参照してください。
