# 引き継ぎ文書 — 語灯 (gotou)

この文書は、企画フェーズ(2026-07-24〜25)から実装フェーズ(Claude Code)への引き継ぎである。
毎回守るルールは各 CLAUDE.md を参照。ここには経緯と現状と直近タスクを書く。

## プロジェクト概要

浄土宗大辞典(https://jodoshuzensho.jp/daijiten/ 、MediaWiki・約1万項目)をスマホで引ける
辞書アプリ。正式名は「語灯(ごとう) ― 浄土のことば辞典」、愛称はマスコットの「ごとうさん」。
主対象は檀家・信徒。開発者は浄土宗僧侶の一人開発(Python経験あり)。

## 現状(2026-07-25時点)

- 開発者の手元に、MediaWikiから取得して macOS 辞書アプリ用 .Dictionary を生成する
  Pythonスクリプトが**ほぼ完成して存在する**。まだこのリポジトリには入っていない。
  **最初に開発者から受け取り、factory/src/ に配置することから始める。**
- 辞書データの利用許諾は未取得。よってデータは一切公開しない(CLAUDE.mdの掟)。
  アプリは将来的に初回起動時ダウンロード構成を想定。
- 検討の経緯全体は docs/plan-2026-07.html(人間の閲覧用・更新不要)。

## 決定事項サマリ

- **技術**: TypeScript/React のPWA。辞書DBは wa-sqlite / sql.js。GitHub Pages + Actions で配信。
  将来 Capacitor でiOS/Androidストア展開。
- **検索**: 読みのインクリメンタル・前方一致が主役。異体字は shared/variants.json で吸収。
  音声入力(kuromoji.jsで読みに戻す)とカメラOCR(収録語スキャン)は後続フェーズ。
  起動時の既定検索モード(文字/音声/カメラ)は設定で切替可能にする。
- **勤行モード**: 差定をプレイリストとして扱う(docs/saijo-spec.md)。ページ送りは
  片手持ち・親指タップが主役。勤行テキストの原文はパブリックドメインなので
  許諾を待たずに実装を進められる。
- **計測**: Plausible/Umami 系。イベントはIndexedDBにキューしてオンライン時送出。
  許諾交渉の材料になる利用数データを取ることが目的。
- **モデル運用**: 実装はSonnet。同一エラー2回失敗で .claude/agents/debugger.md (Opus)に委譲。
  設計はプランモード。

## 最初にやるタスク(推奨順)

1. 既存Pythonスクリプトを factory/src/ に受け入れ、現状を把握する
2. factory: shared/schema.sql に従う SQLite 出力を追加(.Dictionary出力は壊さない)
3. factory: ダミー100項目の fixture 生成スクリプトとテスト
4. app: Vite + React + TS 雛形。fixtureを読む検索UIプロトタイプ(読みインクリメンタル)
5. app: 項目表示 + 項目間リンクのジャンプ
6. app: 勤行モードの骨格(shared/gongyo/ のサンプルunit/presetで動かす)
