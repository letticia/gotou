# 元祖大師御法語 データ置き場

『元祖大師御法語』前篇31章・後篇31章の本文データ。勤行モードの日替わりunit
(`gohogo-daily`)がここを読む。仕様は `docs/saijo-spec.md`。

ここには**公開してよいデータのみ**を置く。

## 収録するもの

- 篇(前篇/後篇)・章番号・章題とその読み
- 御法語の本文と読み仮名(法然上人遺文からの抜粋。著作権保護期間満了=PD)
- 底本名(例「浄土宗略抄」)を含む出典表記

各章の一文要約(`summary`)は**まだ持たせていない**。本文に基づく自前生成が必要で、
62章ぶんの校閲を伴うため後回しにした。勤行モードは要約を表示しないので、
無くても差し支えない(将来の「今日の御法語」読み物画面用)。

## 収録しないもの

- **現代語訳は入れない。** 2010年刊行物に由来する現代の著作物であり、
  権利保護の対象。`factory/cache/` に取得したHTMLには含まれるが、
  変換スクリプトは抽出せず、`shared/` にも `factory/output/` にも書き出さない。
- **サイト掲載の要約文をそのまま使わない。** 将来 `summary` を入れるときは、
  本文と章題からこちらで新しく書き起こす(サイト文の転載にしない)。
  取得元の要約文は `factory/cache/` と、校閲用の対照表
  (`factory/output/`。どちらもコミット対象外)の外には残さない。
  `build_gohogo.py` の `to_output_chapter()` が書き出すフィールドを明示的に
  列挙しているので、取りこぼしで混入することはない(テストで担保)。

## 出典と取得の経緯

本文・読み仮名・章題は知恩院公式サイト「御法語」(<https://www.chion-in.or.jp/okotoba/>)
から取得した。各章の `source` に当該章ページのURLと取得年月を記録している。

知恩院の `robots.txt` は `User-agent: *` の全面禁止こそ置いていないが、
GPTBot・ClaudeBot・Google-Extended 等のAI用クローラを名指しで拒否している。
そのため**取得は開発者自身が手元で行う**こととし、AIエージェントには
実行させない(`factory/src/fetch_gohogo.py` の冒頭にも同じ注意書きがある)。

## 注意

- 本文自体はPDだが、**サイト上のルビ(読み仮名)と章題の表記は現代の編集物である
  可能性がある**。各章の `source.name` に「読みは要点検」と記してあり、
  底本と突き合わせた確認が済んでいない。確認が済んだ章から記述を改めること。
- 元祖大師御法語の章立て・抜粋の選定そのものも編集の産物である点に留意する。
