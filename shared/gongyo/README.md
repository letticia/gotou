# 勤行テキスト・差定プリセット置き場

ここには**公開してよいデータのみ**を置く。

- `units/` … テキスト単位(香偈・三宝礼・四奉請・懺悔偈・十念・開経偈・四誓偈・摂益文など)。
  原文はパブリックドメインの底本に拠ること。各ファイルに出典(底本・取得元URL)を明記。
- `presets/` … 差定プリセット(JSON)。仕様は `docs/saijo-spec.md`。

注意:
- Wikisourceの読みくだし文を使う場合はCC BY-SA(帰属表示+継承)をファイル内に明記。
- 現代の勤行式本のルビ・現代語訳・式次第の編集は出版社の権利物なのでコピーしない。
  ルビは辞書の読みインデックスで自前付与する。
